Caesar Cipher

A simple Caesar Cipher implementation in Python, created as part of the **freeCodeCamp Python Certification**.

- What it does

The program can:

* Encrypt text using a Caesar shift.
* Decrypt encrypted text.
* Work with uppercase and lowercase letters.
* Validate the shift value.

- Example

text
Encrypted: iuhhFrghFdp
Decrypted: freeCodeCamp
