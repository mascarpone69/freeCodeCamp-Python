# RPG Character Creator
A Python program that creates an RPG character based on a character name and three stats: Strength, Intelligence, and Charisma.

## Features

- Validates the character name.
- Checks that all stats are integers.
- Ensures each stat is between 1 and 4.
- Ensures the total number of stat points is 7.
- Displays character stats using full and empty dots.
